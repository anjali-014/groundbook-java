    How it runs
    
  
    
    
    The office PC runs the planner from one image; Sabu's tablet at the gate reaches it on that PC's IP, port 8080. Data lives on a volume, every setting comes from the env-file, logs go to stdout.
    

    docker build -t groundbook .
docker run -d --name groundbook -p 8080:8080 -v groundbook-data:/data --env-file .env groundbook
docker logs -f groundbook
    
    
    The image is built from the Dockerfile you write.
    
  
    
  
    Restart the container
    
  
    
    
    This page cannot restart the container — run the two commands yourself. Press Before restart to keep a copy of Saturday's bookings on all four grounds in this browser, restart, then press After restart to compare.
